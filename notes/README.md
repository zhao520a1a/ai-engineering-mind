# Notes

从外部文章、访谈、手册中提炼出的观点与读书笔记。

区别于 `prompts/`（可复用的提示词资产），这里沉淀的是**别人的思考经我消化后的结构化留存**——原文优先、提要精炼，供日后检索复用。

## 约定

- 新增笔记优先保留原文核心，提要一句话说清"这篇讲了啥"
- 文件名沿用中文主题名，便于检索
- 与 `prompts/` 的区别：那边是"拿来即用的工具"，这边是"消化后的观点沉淀"
